#  Application web Todo Pro
** Projet de fin de formation JavaScript chez Yata-Experts.**
Une application de gestion de tâches sécurisée, pensée comme un vrai tableau de bord productif.

## Fonctionnalités
- Authentification sécurisée
- Dashboard avec statistiques
- Gestion complète des tâches(filtre, recherche)
- Gestion des dossiers
- Calendrier interactif
- Gestion de son compte (modification, suppression du compte)
- Deconnexion
- Page politique de confidentialité
- contact

## Pre-requis
- Installer un navigateur(chrome, safari, edge) si ce n'est deja installé.

## Technologies
- HTML5 / CSS3
- JavaScript ES6+
- LocalStorage / SessionStorage

## Utilisation
- Lancer l'application en ouvrant smplement le fichier `sign.html` pour se connecter a l'application.

## Collaboration
- Les collaborations sont les bienvenues.

## Sécurité
Ce projet represente une app sécurisée sans backend :
- Cryptage des mots de passe
- Validation stricte des formulaires
